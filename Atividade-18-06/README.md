## 🚀 Como usar

### Desafio 01 - Drawer Navigation Básico

```bash
cd desafio-01-app08_DrawerNav01
npm install
npm start
```

**Funcionalidades:**
- ✅ Navegação por menu lateral (Drawer)
- ✅ 3 telas simples

---

### Desafio 02 - Drawer com Componentes

```bash
cd desafio-02-aula08_DrawerNav02
npm install
npm start
```

**Funcionalidades:**
- ✅ Drawer com 4 telas
- ✅ FlatList de receitas
- ✅ Switch para ingredientes
- ✅ Slider para tamanho de fonte
- ✅ Tema: Receitas de Cozinha

---

### Desafio 03 - TAB + DRAWER Navigation

```bash
cd desafio-03-aula08_DrawerNav03
npm install
npm start
```

**Funcionalidades:**
- ✅ Navegação por Abas (Tabs)
- ✅ Navegação por Menu Lateral (Drawer)
- ✅ Combinação dos 2 tipos

---

### Desafio 04 - STACK + TAB + DRAWER Navigation

```bash
cd desafio-04-aula08_DrawerNav04
npm install
npm start
```

**Funcionalidades:**
- ✅ Navegação por Pilha (Stack)
- ✅ Navegação por Abas (Tabs)
- ✅ Navegação por Menu Lateral (Drawer)
- ✅ Integração dos 3 tipos
